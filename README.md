# PRAA-FL

## Prototype Reliability-Aware Adaptive Aggregation for Federated Medical Image Classification

### Base Paper

FLAME: Federated Learning With Masked Autoencoders and Mean-Prototypes Embedding for Sparsely Labeled Medical Images

### Research Idea

PRAA-FL extends FLAME by introducing:

- Prototype Reliability Assessment Module (PRAM)
- Prototype Reliability Score (PRS)
- Prototype Reliability-Aware Adaptive Aggregation (PRAA)

to improve federated medical image classification under non-IID environments.
